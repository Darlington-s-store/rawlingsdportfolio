# Asomani Rawlings Junior - Software Engineer Portfolio

Personal portfolio showcasing full-stack development projects, technical skills, and professional experience.

## Tech Stack
- **Frontend**: React, Next.js, Tailwind CSS, Shadcn UI
- **Backend**: Node.js, Express.js, PostgreSQL, MySQL
- **Tools**: Vite, Firebase, Git

## Projects
- **Rudi Finds Jem**: Bespoke wedding management and event coordination platform.
- **Nova Eye Care Services**: Healthcare portal for appointment booking and patient management.
- **AtlasWave Travel & Tours**: AI-powered tour discovery and booking platform.
- **Fun Lovable Learning Platform**: EdTech solution with gamified learning and student analytics.
- **Elshadai Millenium Travel & Shopping**: Premium travel consultancy and study abroad platform.

## Setup & Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Darlington-s-store/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run developmental server:
   ```bash
   npm run dev
   ```
